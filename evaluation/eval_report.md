# SWE-bench Lite Evaluation Report

**Status: not yet run.**

This file is generated by `evaluation/run_swebench_eval.py report` after you:

1. Download SWE-bench Lite and build the 90-instance stratified sample
   (`data/swebench/download_swebench.py` + `prepare_instances.py`).
2. Generate predictions with the baseline and full-system configurations
   (`run_swebench_eval.py generate --config baseline|full_system`), which
   requires a valid `OPENAI_API_KEY` and, for the full system, a running
   local Llama-3 server (Ollama or vLLM).
3. Grade both prediction files with the **official** SWE-bench harness
   (`run_swebench_eval.py grade`), which requires Docker and will build one
   evaluation image per instance.
4. Run `report` to produce the real baseline-vs-full-system comparison
   table, broken down by repository and difficulty.

No numbers are hardcoded anywhere in this codebase. The portfolio spec's
reference figures (16/90 baseline -> 24/90 full system) are illustrative
targets for what this architecture is capable of, not numbers we have
fabricated here — see the top-level README for why we're not reporting a
score without having actually run the harness (this environment has no
OpenAI API access, no GPU, and no Docker daemon available to it).

Once you run the commands above on your own infrastructure, replace this
file's contents with the generated report.
